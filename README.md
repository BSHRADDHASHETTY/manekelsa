# Mane-Kelsa

Mane-Kelsa is an Android application developed using Kotlin and Jetpack Compose.

## Features
- OTP Login Authentication
- Worker Profile Creation
- Search Workers by Area
- Secure Login
- Attractive UI Design

## Technologies Used
- Kotlin
- Jetpack Compose
- Firebase Authentication
- Android Studio
